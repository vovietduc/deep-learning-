# Labs 2 – Project Description

**Topic:** Sentiment Analysis with LSTM.

**Goal:** Classify movie reviews as positive or negative.

**Dataset:** IMDb Reviews – https://ai.stanford.edu/~amaas/data/sentiment/

**Main model:** Embedding + LSTM + Dense (Linear).

**Task type:** Binary classification.

**Extensions:** GRU, Bidirectional LSTM and GloVe embeddings.

**Expected deliverables:** Problem/scope report, sample data and description, source code, installation/run guide, demo, baseline comparison, error analysis and limitations.
